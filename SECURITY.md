# Security Policy

## Supported Versions

Security updates are provided for the latest released version of `pytestquick`.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

Users are encouraged to upgrade to the latest available release before reporting a security issue.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

If possible, use GitHub's private vulnerability reporting feature for this repository.

Alternatively, security vulnerabilities may be reported by email to:

**[security@fifoa.com](mailto:security@fifoa.com)**

Please include enough information to help us understand and reproduce the issue, including:

* A description of the vulnerability and its potential impact
* The affected version or versions
* Steps or sample input that reproduce the issue
* Any known mitigations or workarounds
* Any other relevant technical details

We will make a reasonable effort to acknowledge security reports promptly and will provide updates as the issue is investigated.

If a vulnerability is confirmed, we will work to develop and release an appropriate fix and coordinate disclosure when necessary.

If a report is determined not to represent a security vulnerability, we will explain that determination when practical.

## Responsible Disclosure

We ask that reporters give the maintainers a reasonable opportunity to investigate and address confirmed vulnerabilities before publicly disclosing them.

Thank you for helping keep `pytestquick` and its users secure.
